# Name selection

Checked September 7, 2026, 02:45 UTC (September 6 in Colombia).

Selected display name: **Abástelo ERP**. URLs and package identifiers use `abastelo`. The name refers to *abasto* and *abastecer*, which fit retail and wholesale operations. Use the name without a tagline.

## Why Nexo was replaced

- [Nexo ERP, Colombia](https://nexoerp.com.co/nexo-erp/) markets POS, inventory, invoicing and business management software. Its site lists a Santa Marta address.
- [Nexo, Nexoftware](https://www.nexoftware.com/) markets ERP, CRM and POS software under the same name.
- [Nexo ERP, Chile](https://getnexo.app/) markets an ERP with sales, purchasing, inventory and finance modules.

These are direct software-category conflicts, including one in the intended Colombian market.

This is preliminary naming research, not proof of worldwide exclusivity or trademark clearance. No formal trademark-register or phonetic-conflict search was completed. Colombia's [SIC trademark resources](https://sedeelectronica.sic.gov.co/temas/propiedad-industrial/marcas) link to SIPI and international search tools for that separate review. Domain and store availability can change.

## Compatibility

Visible branding and app display names use Abástelo. Package labels and export filenames use the ASCII spelling `abastelo`. Existing native bundle IDs, device storage keys, cookies, API headers and deployment resource identifiers remain stable so the rename does not disconnect installed clients or select a different business database. The GitHub repository remains `ethanrimes/pyme-colombia`.
